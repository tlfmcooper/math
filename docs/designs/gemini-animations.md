# Design: Gemini-Powered Interactive Math Animations

Generated by /plan-ceo-review on 2026-03-18
Branch: main | Mode: SCOPE_EXPANSION

## Vision

### The Problem
When a Grade 1 child gets a math question wrong, they currently see a grid of apple emojis with a text explanation. Kids click Next without understanding. The chatbot exists but its visual output doesn't produce the "motion = explanation" quality that Grade 1 learners need.

### 10x Target
When a child gets "3 + 5 = ?" wrong, a full theatrical math scene plays: objects drop from the sky one-by-one (with *plink* sounds), more fly in from the right, a cartoon hand groups them all, a number appears above each group, then they merge with a burst of confetti and the answer zooms into frame — narrated live by the mascot. The child can tap any object to hear it counted. They can replay it, slow it down, then draw it themselves.

### Platonic Ideal
Zero text explanation needed. Pure visual-kinesthetic math storytelling. Each math concept has its own "animation grammar" — addition always uses grouping, subtraction always shows removal, skip counting always uses hops on a number line. Kids recognize the grammar and learn to read it. The AI doesn't describe math; it *performs* it.

## Architecture

### Data flow

```
Wrong answer
    │
    ├──► Mascot: "Let me show you!" (immediate, local)
    │
    ▼ POST /api/chat
chatbot.py (extended Pydantic schema)
    │
    ▼ Gemini returns AnimationScript
{
  reply: str,
  animation: {
    grammar: "ten_frame"|"number_line"|"grouping"|"removal"|"coins"|"hops",
    steps: [
      {id, objects: [{emoji, label}], action, narration, sound, duration_ms},
      ...  (max 5 steps, max 15 objects per step)
    ]
  }
}
    │
    ▼
AnimationEngine (static/animation-engine.js)
    ├──► renderStep(step, speed) — positions DOM divs, plays sound
    ├──► syncMascot(step.narration) — Web Speech API
    ├──► choreographMascot(step.id) — mascot slides into frame (tablet+)
    └──► onComplete()
            ├──► Replay button (▶ Watch Again)
            ├──► Speed toggle (🐢 Slow)
            ├──► Mute toggle (🔇/🔊)
            ├──► Draw-along prompt (✏️ Draw it!)
            └──► Objects remain tappable → speak count number
```

### New files
- `static/animation-engine.js` — `AnimationEngine` class (~200 LOC) + `DrawAlongCanvas` class (~80 LOC)

### Modified files
- `chatbot.py` — extend Pydantic schema (AnimationScript, AnimationStep, AnimationObject), add grammar field, update system prompt with strand grammar hints, add ValidationError rescue
- `templates/quiz.html` — load animation-engine.js, replace `renderAnimation()` with `AnimationEngine.play()`, extract `handleChatResponse()`, add toolbar
- `static/style.css` — new keyframes: flyIn, dropBounce, hopAlong, revealPop

## Critical Implementation Requirements

### 4 Critical Gaps (must fix in implementation)

1. **Pydantic ValidationError rescue** — `chatbot.py` must catch `pydantic.ValidationError` and return `{reply, animation: null}` instead of 500
2. **Empty steps fallback** — `AnimationEngine.play()` must check `steps.length > 0` before rendering; fall back to old emoji grid if empty
3. **Cancel on Next** — `loadQuestion()` must call `AnimationEngine.cancel()` first to clear orphaned `setTimeout` callbacks
4. **Null object guard** — each step must check `step.objects` is valid before rendering; skip invalid steps, continue sequence

### Security
- Animation step narrations rendered as `textContent` (not `innerHTML`) — prevents XSS via Gemini prompt injection
- Pydantic schema enforces `Field(le=5)` on steps, `Field(le=15)` on objects per step

### Key design decisions (resolved)
- **DOM elements, not Canvas** — objects are positioned `div`s so tap-to-count stays trivial via `onclick`
- **No streaming for structured output** — show engaging loading state (mascot "thinking" phrase) instead; structured JSON can't be partially parsed
- **Single AudioContext** — created on mood selection click (user gesture), reused for all sounds
- **Mascot choreography disabled on < 480px** — avoid layout issues on small phones
- **Mute state** — 🔇/🔊 toggle in quiz header, persisted in localStorage, defaults ON

## Strand Animation Grammar Map

| Strand | Grammar | Visual |
|--------|---------|--------|
| number, wordproblems | grouping | Objects appear in two groups, merge with count |
| algebra | grouping | Balance/equal groups |
| skipcounting | hops | Number line with frog hops |
| placevalue | ten_frame | 10-frame grid fills up |
| comparing | grouping | Two side-by-side columns |
| spatial, measurement | show | Objects scale/position to show concept |
| financial | coins | Canadian coin objects (loonie, toonie, etc.) |
| data | grouping | Bar chart-style stacking |
| time | show | Clock hands move |
